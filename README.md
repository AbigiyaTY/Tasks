# Tasks App <a name="about-project"></a>

 Android project developed that demonstrates the use of data classes, enums, composable functions, layouts, and reusable UI components to display tasks with different priority levels.


## 🛠️ Built With

- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose
- **Architecture:** Android Activity + Composable Functions
- **Design System:** Material Design 3
- **Development Environment:** Android Studio
- **SDK:** Android SDK

### Key Features <a name="key-features"></a>
---

- ✅ Display student tasks in a modern Compose UI
- ✅ Support task priorities (LOW, MEDIUM, HIGH)
- ✅ Reusable `TaskRow` component with checkbox and priority label
- ✅ Material Design 3 styling
- ✅ Task model implemented using Kotlin data classes


## 💻 Getting Started <a name="getting-started"></a>

To get a local copy up and running, follow these steps.

## Prerequisites

Before running this project, make sure you have:

- Android Studio installed
- Android SDK configured
- Kotlin support enabled
- An Android Emulator or physical Android device

## Setup

Clone this repository:

```sh
git clone https://github.com/AbigiyaTY/Tasks.git
```

Navigate to the project directory:

```sh
cd Tasks
```

## Install

Open the project in Android Studio:

```sh
File → Open → Select Project Folder
```

Allow Android Studio to download and sync all required dependencies.

## Usage

This project demonstrates:

- Kotlin data classes
- Enum classes
- Functions and string templates
- Jetpack Compose UI development
- Material 3 components
- Layouts using Column and Row
- Reusable composables

Users can view tasks and their priorities in a clean Compose interface.

## Run the App

Run the application using Android Studio:

```sh
Run > Run 'app'
```

Or use the keyboard shortcut:

```sh
Shift + F10
```

The application will launch on the selected emulator or Android device.
